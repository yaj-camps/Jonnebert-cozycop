# CozyCup Cafe

# Project Description

This repository contains a simple front-end web project created for academic purposes. The project demonstrates basic web development concepts using HTML and CSS and is intended to run directly in a web browser.

## Features

- Cafe-themed website design
- Responsive layout for better viewing
- Organized menu and content sections
- Clean and simple user interface
